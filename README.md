# Calculadora utilizando Pilha em C

## Descrição
Este projeto foi desenvolvido na linguagem C utilizando a estrutura de dados Pilha (Stack). O programa simula uma calculadora que realiza operações matemáticas e armazena os resultados em uma pilha.

## Funcionalidades
- Visualizar o elemento que está no topo da pilha.
- Exibir todos os elementos armazenados na pilha.
- Realizar operações de adição.
- Realizar operações de subtração.
- Realizar operações de divisão.
- Realizar operações de multiplicação.
- Armazenar os resultados das operações na pilha utilizando Push.
- Remover o último elemento inserido utilizando Pop.
- Verificar se a pilha está vazia.
- Verificar se a pilha está cheia.

## Estrutura de dados
O programa utiliza uma pilha implementada com um vetor de inteiros de tamanho 10.

A estrutura segue o princípio LIFO (Last In, First Out), ou seja, o último elemento inserido é o primeiro a ser removido.

### Principais funções

- `vazia()`: verifica se a pilha está vazia.
- `push()`: adiciona um novo elemento ao topo da pilha.
- `pop()`: remove o último elemento inserido na pilha.

## Tecnologias utilizadas
- Linguagem C
- Biblioteca stdio.h

## Como funciona
O programa apresenta um menu interativo no terminal, permitindo que o usuário escolha uma operação matemática ou uma funcionalidade da pilha.

Após realizar uma operação matemática, o resultado é armazenado automaticamente na pilha. O usuário também pode visualizar os resultados armazenados ou remover o último elemento inserido.

## Objetivo
Praticar os conceitos de estrutura de dados Pilha, utilizando as operações Push e Pop, além de trabalhar com vetores, funções, estruturas condicionais e estruturas de repetição.
